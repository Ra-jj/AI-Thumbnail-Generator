# AI Thumbnail Generator

A full-stack AI Thumbnail Generator application built with the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) and standard JavaScript. 

The application allows users to register, log in, and securely access AI-powered thumbnail generation features. 

## Features
- **Secure Authentication:** JWT for token-based authentication and bcrypt for password hashing.
- **AI Integration:** Seamlessly generate custom thumbnails based on user prompts.
- **Modern UI:** Built with React.js (Vite) and styled with Tailwind CSS for a fully responsive, sleek interface.
- **RESTful API:** Robust backend using Express.js and MongoDB for efficient data storage and user management.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Frontend**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   *(To build for production, run `npm run build`)*

2. **Backend**
   ```bash
   cd backend
   npm install
   npm run server
   ```
   *(The backend server will run via nodemon for development).*

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, JavaScript (`.jsx`)
- **Backend:** Node.js, Express, MongoDB, JavaScript (`.js`)
